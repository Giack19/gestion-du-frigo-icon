Gestion du Frigo

Lors de votre première utilisation, vous pouvez ajouter cette application à votre écran d’accueil.

Sur iPhone :
1. Ouvrir cette page dans Safari
2. Appuyer sur Partager
3. Choisir « Ajouter à l’écran d’accueil »

Sur Android :
1. Ouvrir cette page dans Chrome
2. Ouvrir le menu ⋮
3. Choisir « Ajouter à l’écran d’accueil »
Ouvrir Gestion du Frigo
L’installation sur l’écran d’accueil est facultative.
